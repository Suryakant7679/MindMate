# GoEmotions hard-label dataset

`goemotions_hardlabels.csv` contains 57,732 examples for emotion-classification experiments.

- `text`: the text being labelled.
- The remaining 28 columns are binary (`0` or `1`) hard labels: 27 emotion classes and `neutral`.

The file is included for future emotion-understanding work. It is not currently consumed by the local Llama chat API, and the Mood Tracker continues to display illustrative values.
